# Changelog

## 0.1.0 - 2026-06-03

Initial release-ready package.

- Native Hermes entry-point plugin for attached iPhone automation.
- Static Hermes-owned iPhone tool catalog with USB/usbmux, WebDriverAgent, semantic UI, Messages, and guarded side-effect flows.
- Hermes-native approval integration for text-message send/reply actions.
- Dashboard tab with status/read panels, timeout-safe overview, redacted payloads, and confirm-gated quick actions.
- Packaged dashboard assets mirrored into the Hermes plugin dashboard directory during registration.
- Tests for registration, backend behavior, semantic operations, safety/approval, WDA lifecycle, and dashboard API/assets.
